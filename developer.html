          Printer

          Set up for the Elegoo Neptune 4 Plus. Enter the printer's IP address once and every order on the bench gets an Open printer button next to its file.

          Find the address

          Connect the printer to Wi-Fi on its touchscreen, then open Settings and About Machine. The IP address is listed there and looks like 192.168.1.50.

          Sending a job

          1. On the order, tap Open file and download the model.
          2. Slice it in ElegooSlicer or OrcaSlicer with the Neptune 4 Plus profile.
          3. Tap Open printer, upload the sliced file on the printer's page and start the print.
          4. Back here, move the order to Printing.

          Open printer only works while your phone or computer is on the same Wi-Fi as the printer. The slicer can also send the job straight to the printer if you add the same IP address there.

          Backup

          Orders and numbers are saved on this device only. Copy the backup text somewhere safe before switching phones or clearing your browser.
